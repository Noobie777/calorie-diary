Async Notes & Examples

Core Idea

Async is useful for I/O-bound work (database calls, APIs, file operations).

A coroutine only gives control back to the event loop when it:

* reaches an await
* finishes execution

Without an await, a coroutine runs like normal Python code and cannot be interrupted.

⸻

async_test

async def async_test():
    await asyncio.sleep(5)
    return {"message": "Async worked"}

What it demonstrates

* await pauses the coroutine.
* The event loop can run other coroutines while this one is sleeping.
* This is cooperative multitasking.

Important

await asyncio.sleep(5)

is non-blocking.

time.sleep(5)

blocks the thread.

⸻

sync_test

def sync_test():
    time.sleep(5)
    return {"message": "Sync worked"}

What it demonstrates

* Traditional synchronous execution.
* The thread is blocked for 5 seconds.
* No coroutine can use this thread during the sleep.

⸻

coroutine_test

async def greet():
    return "hello"
result = await greet()

What it demonstrates

Calling:

greet()

does NOT execute the coroutine.

It returns a coroutine object.

Execution begins when:

await greet()

is used.

⸻

gather_test

results = await asyncio.gather(
    task1(),
    task2()
)

What it demonstrates

* Start multiple coroutines together.
* Wait until all of them finish.
* Useful when tasks are independent.

Important

Concurrency only happens when tasks reach an await.

If task1 never yields control, task2 cannot run until task1 finishes.

⸻

task_test

asyncio.create_task(bg_task())

What it demonstrates

* Schedule a coroutine in the background.
* Current function continues immediately.
* Does NOT wait for completion.

Difference from gather

gather()

* Start tasks
* Wait for them

create_task()

* Start tasks
* Continue execution immediately

⸻

cancel_test

task.cancel()

What it demonstrates

* Request cancellation of a running task.
* Cancellation appears as:

asyncio.CancelledError

inside the coroutine.

Important

Cancellation is cooperative.

The coroutine must reach an await point before cancellation can be processed.

⸻

switch_test

await asyncio.gather(
    worker("A"),
    worker("B")
)

What it demonstrates

How the event loop switches between coroutines.

Flow:

A starts
A sleeps
B starts
B sleeps
A wakes up
A finishes
B wakes up
B finishes

The event loop switches at await points.

⸻

timeout_test

await asyncio.wait_for(
    slow_task(),
    timeout=3
)

What it demonstrates

Limit how long a coroutine is allowed to run.

If timeout is exceeded:

asyncio.TimeoutError

is raised.

Important

wait_for(gather(...))

applies the timeout to the ENTIRE gather operation, not each child task individually.

⸻

Quick Mental Model

Sequential:

await task1()
await task2()

Flow:

task1
↓
task2

Concurrent:

await asyncio.gather(
    task1(),
    task2()
)

Flow:

task1 ─┐
       ├─ running together
task2 ─┘

Background:

asyncio.create_task(task1())

Flow:

task1 starts
↓
current function continues immediately

⸻

Rule of Thumb

Use:

* await → when task result is needed immediately
* gather → when multiple independent tasks can run together
* create_task → when work should continue in background
* wait_for → when a timeout is needed

Async is for I/O-bound work.

CPU-heavy work should use worker processes/queues instead of asyncio.

#Async learning. Test Endpoints.
@app.get("/async-test")
async def async_test():

    await asyncio.sleep(5)

    return {"message": "Async worked"}

@app.get("/sync-test")
def sync_test():
    time.sleep(5)
    return {"message": "Sync worked"}

@app.get("/coroutine-test")
async def coroutine_test():

    async def greet():

        return "hello"

    result = await greet()

    return {

        "result": str(result)

    }

@app.get("/gather-test")
async def gather_test():
    result = []
    async def task1():
        await asyncio.sleep(5)
        return "task1 done"
    async def task2():
        await asyncio.sleep(5)
        return "task2 done"
    # results = await asyncio.gather(
    #     task1(),
    #     task2()
    # )
    result.append(await task1())
    result.append(await task2())
    return {"results": result}

@app.get("/task-test")
async def task_test():
    async def bg_task():
        print("task started")
        await asyncio.sleep(2)
        raise Exception("task failed")
    asyncio.create_task(bg_task())
    return {"result": "Request returned"}

@app.get("/cancel-test")
async def cancel_test():
    async def worker():
        try:
            print("worker started")
            await asyncio.sleep(10)
            print("worker finished")
        except asyncio.CancelledError:
            print("worker cancelled")
            raise
    task = asyncio.create_task(worker())
    await asyncio.sleep(2)
    task.cancel()
    return {"message": "task cancelled"}

@app.get("/switch-test")
async def switch_test():
    async def worker(name):
        print(f"worker {name} started")
        await asyncio.sleep(10)
        print(f"worker {name} finished")
    await asyncio.gather(worker("A"), worker("B"))
    return {"message": "finished"}

@app.get("/timeout-test")
async def timeout_test():
    async def slow_task():
        await asyncio.sleep(10)
        return "slow_task finished"
    try:
        result = await asyncio.wait_for(slow_task(), timeout=3)
    except asyncio.TimeoutError:
        return {"error": "Task timed out"}
